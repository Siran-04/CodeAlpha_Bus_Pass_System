Bus Pass Management System

About the Project

The Bus Pass Management System is a beginner-friendly web application developed as part of the CodeAlpha Internship.

It helps students apply for a bus pass by entering their personal and travel details.

Technologies Used

- Java
- Javalin
- MySQL
- HTML
- CSS
- Maven

Features

- Student bus pass application form
- Student and travel details collection
- MySQL database connectivity
- Bus pass application storage

How to Run

1. Install Java and Maven.
2. Install MySQL and create the "bus_pass_db" database.
3. Configure your MySQL credentials securely in the Java application.
4. Open the project folder in VS Code.
5. Run "mvn clean compile".
6. Start the application using the configured Maven command.
7. Open "http://localhost:7070" in your browser, or use the port configured in the application.
